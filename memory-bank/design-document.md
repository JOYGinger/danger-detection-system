# 危险检测集成系统 - 产品设计文档

## 1. 产品概述

### 1.1 产品定位
一款面向个人用户的独立安全检测工具，用户通过手动输入文本内容即可快速检测常见网络威胁。

### 1.2 核心价值
- 无需复杂配置，即装即用
- 本地检测，保护隐私
- 简单易用的Web界面

### 1.3 目标用户
个人用户、普通网民、开发者

---

## 2. 功能需求

### 2.1 检测功能

| 威胁类型 | 输入方式 | 检测方式 | 输出结果 |
|---------|---------|---------|---------|
| AI生成的钓鱼邮件 | 文本内容 | NLP文本特征分析+AI模式识别 | 风险等级（高/中/低）+ 判定依据 |
| 弱密码检测 | 文本内容 | 密码强度规则分析+熵值计算 | 风险等级 + 密码强度评分 |
| 敏感信息泄露检测 | 文本内容 | 正则匹配+规则分析 | 泄露类型 + 风险等级 + 掩码建议 |

### 2.2 用户交互功能

| 功能 | 描述 |
|-----|------|
| 文本检测 | 输入邮件文本、密码或代码进行检测 |
| 检测历史 | 保存历史检测记录，可查看和删除 |
| 结果展示 | 清晰展示风险等级、判定依据、修复建议 |

### 2.3 非功能性需求

| 需求项 | 说明 |
|-------|------|
| 响应时间 | 单次检测不超过10秒 |
| 隐私保护 | 所有检测在本地执行，不上传用户数据 |
| 易用性 | 无需配置，打开即用 |

## 3. 技术架构

### 3.1 技术选型

| 层级 | 技术方案 |
|-----|---------|
| 前端 | React + TypeScript + Tailwind CSS |
| 后端 | Python FastAPI |
| 检测引擎 | 自研规则引擎 + 正则匹配 |
| 存储 | SQLite（本地存储） |
| 部署 | Docker Compose |

┌─────────────────▼───────────────────────┐
│            API 服务 (FastAPI)            │
│  ┌─────────────────────────────────────┐│
│  │         检测引擎                     ││
│  │  ┌─────────┐ ┌─────────┐ ┌────────┐ ││
│  │  │钓鱼邮件  │ │ 弱密码   │ │敏感信息 │ ││
│  │  │ 检测器   │ │ 检测器   │ │ 检测器 │ ││
│  │  └─────────┘ └─────────┘ └────────┘ ││

│  │         存储层 (SQLite)              ││

## 5. 部署设计

### 5.1 Docker Compose 配置

```yaml
version: '3.8'
services:
  web:
    build: ./frontend
    ports:
      - "3000:3000"
  api:
    build: ./backend
    ports:
      - "8000:8000"
    volumes:
      - ./data:/app/data
```

### 5.2 目录结构

```
.
├── docker-compose.yml
├── frontend/
│   ├── Dockerfile
│   └── src/
├── backend/
│   ├── Dockerfile
│   ├── app/
│   │   ├── main.py
│   │   ├── detectors/
│   │   └── models/
│   └── requirements.txt
└── data/
    └── database.db
```

## 7. 验收标准

1. 用户输入文本内容后，5秒内返回检测结果
2. 检测结果包含风险等级和判定依据
3. 历史记录正确保存和展示
4. Docker部署后可直接访问Web界面
5. 所有界面文字为简体中文
