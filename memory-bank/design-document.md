# 危险检测集成系统 - 产品设计文档

## 1. 产品概述

### 1.1 产品定位
一款面向个人用户的独立安全检测工具，用户通过手动输入文本内容即可快速检测常见网络威胁。

### 1.2 核心价值
- 无需复杂配置，即装即用
- 本地检测，保护隐私
- 简单易用的Web界面

### 1.3 目标用户
个人用户、普通网民、开发者、信息安全学习者

## 3. 功能需求

### 3.1 检测功能

| 威胁类型 | 输入方式 | 检测方式 | 输出结果 |
|---------|---------|---------|---------|
| AI生成的钓鱼邮件 | 文本内容 | TF-IDF + RandomForest | 风险等级 + 置信度 + 判定依据 |
| 弱密码检测 | 文本内容 | zxcvbn-python | 风险等级 + 强度评分 + 熵值 + 改进建议 |
| 敏感信息泄露检测 | 文本内容 | 正则 + 规则引擎 | 检测类型 + 掩码值 + 位置 + 风险等级 |

### 3.2 用户交互功能

| 功能 | 描述 |
|-----|------|
| 文本检测 | 输入邮件文本、密码或代码进行检测 |
| 检测类型选择 | 支持单类型检测或全部检测 |
| 检测历史 | 保存历史检测记录，可查看和删除 |
| 结果展示 | 清晰展示风险等级、判定依据、修复建议 |

### 3.3 非功能性需求

| 需求项 | 说明 |
|-------|------|
| 响应时间 | 单次检测不超过5秒 |
| 隐私保护 | 所有检测在本地执行，不上传用户数据 |
| 数据安全 | 敏感数据加密存储 |
| 易用性 | 无需配置，打开即用 |

## 4. 技术架构

### 4.1 技术选型

| 层级 | 技术方案 | 信息安全考量 |
|-----|---------|-------------|
| 前端 | React + TypeScript + Tailwind CSS | 类型安全，减少运行时错误 |
| 后端 | Python FastAPI | 自动API文档，便于安全审计 |
| 检测引擎 | TF-IDF+RF / zxcvbn / 正则引擎 | 成熟算法，社区验证 |
| 加密存储 | Fernet (AES-128-CBC + HMAC) | 认证加密，防篡改 |
| 存储 | SQLite | 轻量级，本地部署 |
| 部署 | Docker Compose | 容器隔离，安全边界 |

## 6. 安全设计

### 6.1 数据安全

| 安全措施 | 实现方式 | 保护目标 |
|---------|---------|---------|
| 敏感数据加密 | Fernet (AES-128-CBC + HMAC) | 存储安全 |
| 密钥管理 | 环境变量，不硬编码 | 密钥安全 |
| 数据掩码 | 展示时掩码处理 | 隐私保护 |
| 最小化存储 | 仅保存必要数据 | 数据最小化原则 |

### 6.2 应用安全

| 安全措施 | 实现方式 | 保护目标 |
|---------|---------|---------|
| 输入验证 | Pydantic模型验证 | 注入防护 |
| CORS配置 | 仅允许可信源 | 跨域防护 |
| 错误处理 | 不泄露敏感信息 | 信息泄露防护 |

### 6.3 密钥管理

```
应用启动流程:
1. 读取 ENCRYPTION_KEY 环境变量
2. 未设置 → 报错退出（安全默认）
3. 已设置 → 初始化加密器
4. 正常运行

密钥生成命令:
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

## 7. 部署设计

### 7.1 Docker Compose 配置

```yaml
version: '3.8'
services:
  web:
    build: ./frontend
    ports:
      - "3000:80"
    depends_on:
      - api
  api:
    build: ./backend
    ports:
      - "8000:8000"
    volumes:
      - ./data:/app/data
    environment:
      - ENCRYPTION_KEY=${ENCRYPTION_KEY}
```

## 9. 验收标准

1. 用户输入文本内容后，5秒内返回检测结果
2. 检测结果包含风险等级、置信度和判定依据
3. 历史记录正确保存（加密存储）和展示（解密后）
4. Docker部署后可直接访问Web界面
5. 所有界面文字为简体中文
6. 敏感数据加密存储，密钥不硬编码
7. ENCRYPTION_KEY未设置时应用报错退出
